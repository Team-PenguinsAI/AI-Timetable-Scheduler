1. Executive Summary

Academic course scheduling is an NP-complete problem. This project designs and implements an end-to-end college timetable scheduler satisfying 9 hard constraints (H1-H9) and optimizing 5 soft constraints (S1-S5) using Constraint Satisfaction Problems (CSP) and stochastic local search algorithms.

2. Problem Formulation

Formal CSP: ⟨X, D, C⟩
Variables (X): Each lecture/lab hour = Session(class, subject, session_idx, is_lab, teacher)
Domains (D): Triples (day, period, room) pre-filtered by unary constraints (lunch, room type, capacity, availability)
Cost Function: Cost = 1000 × (Hard Violations) + (Soft Penalties)

5. Analysis of Results (Analytical Questions)

1. Which method was faster?
Min-Conflicts local search was the fastest solver overall, reaching clash-free assignments in 0.001s to 0.005s. Because domain values are pre-pruned by unary constraints, Min-Conflicts repairs remaining binary conflicts in fewer than 2 iterations on average.
2. Which gave better soft-constraint quality?
Simulated Annealing and the Hybrid CSP+SA approach produced dramatically superior soft-constraint quality. While systematic backtracking halts at the first feasible leaf node (penalty ~237-837), Simulated Annealing optimizes soft constraints down to 0.4 - 20 points!
3. What happens as the problem grows?
Unconstrained backtracking has worst-case exponential branching O(d^n), which blows up when bottlenecks cause thrashing. MRV and Forward Checking prune doomed subtrees early. Min-Conflicts scales approximately linearly in under-constrained settings.
4. When would you use each method?
Use Min-Conflicts for instantaneous schedule generation. Use Heuristic Backtracking when a mathematical proof of feasibility/infeasibility is needed. Use Hybrid CSP+SA for production college administration where institutional quality and teacher preferences are critical.
